# 그누보드5

그누보드5는 PHP와 MySQL 또는 MariaDB 기반의 오픈소스 CMS입니다. 게시판과 회원 관리 기능을 제공하며 쇼핑몰 솔루션 영카트를 포함합니다.

## 다운로드

- [GitHub 저장소](https://github.com/gnuboard/gnuboard5)에서 소스 코드를 받을 수 있습니다.
- [SIR 그누보드5 다운로드](https://sir.kr/boards/g5_pds)에서 배포본을 받을 수 있습니다.

## 버전 확인

현재 소스 코드의 버전은 [`version.php`](version.php)에서 확인할 수 있습니다.

## 설치

1. 내려받은 소스 코드를 웹 서버의 서비스 경로에 배치합니다.
2. 브라우저에서 해당 주소로 접속하여 설치 화면을 엽니다.
3. 화면의 안내에 따라 데이터 디렉터리를 준비하고 필요한 권한을 설정합니다.
4. 라이선스를 확인한 뒤 데이터베이스와 최고관리자 정보를 입력하여 설치합니다.

설치 환경과 자세한 절차는 [그누보드5 공식 매뉴얼](https://sir.kr/manuals/g5/1)을 확인하십시오.

> 기존 사이트에 재설치하면 데이터가 삭제될 수 있습니다. 진행하기 전에 파일과 데이터베이스를 백업하십시오.
