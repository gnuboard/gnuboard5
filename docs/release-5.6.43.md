# 그누보드(영카트) 5.6.43 배포 안내

변경 기준은 5.6.42입니다. KCP 현금영수증 처리의 권한 검증과 거래 정합성을 보완하는 보안 업데이트입니다. **이번 버전에는 새 DB 변경이 없습니다.** 이전 버전에서 누락한 DB업그레이드는 먼저 완료하십시오.

## 변경 사항

- **KVE-2026-2513**: 현금영수증 처리 시 실제 주문·개인결제의 존재, 요청자의 권한, 수납 상태와 발급 가능 여부를 서버에서 확인합니다.
- 세션·주문·작업에 결합된 일회용 토큰과 DB 처리 상태로 위조 요청과 중복 발급을 차단합니다. 현재 화면에서 사용하지 않는 직접 조회·취소 요청은 거절합니다.
- 금액·세액·주문자·가맹점 정보는 요청값 대신 주문 원장과 서버 설정으로 구성합니다.
- 개인결제는 전액 수납된 독립 결제만 발급할 수 있습니다. 주문에 연결된 개인결제는 해당 주문에서 처리합니다.
- 승인 후 저장 실패 시 해당 거래만 보상 취소하고, 저장 응답 유실은 원장을 재조회합니다. 결과 불명·취소 실패는 관리자 확인 상태를 유지합니다.
- 관리자 주문·개인결제 화면에 처리 확인번호와 확인 필요 안내를 표시합니다.
- KCP 모듈의 PHP 8.4 동적 속성 경고, 기본·테마 푸터의 실행시간 변수 경고, 서버 IP 변수가 없는 환경의 쇼핑몰 설정 경고를 보완합니다.

## 업데이트 방법

1. 파일과 DB를 백업하고 진행 중인 현금영수증 발급이 없는 유지보수 시간에 적용합니다.
2. 5.6.42 설치본에 전체 소스 또는 `gnuboard5.6.43.patch.zip`을 적용합니다. 처리 파일·발급 폼·결과 화면·공통 라이브러리·관리자 안내를 함께 반영하십시오. 사용자 수정 파일에도 변경 내용을 병합해야 합니다.
3. 이번 버전의 새 DB 마이그레이션과 삭제 파일은 없습니다. 이전 버전의 누락된 업그레이드는 관리자 DB업그레이드에서 완료하십시오.
4. 적용 전에 열어둔 발급 화면은 닫고 다시 여십시오. 이전 폼의 토큰 없는 요청은 거절됩니다.
5. 관리자와 주문자의 정상 발급, 타인 주문 접근 차단, 금액·발급 상태를 확인하고 운영을 재개합니다.
6. 처리 확인 필요 거래는 KCP 거래 내역과 원장을 대조한 뒤 조치합니다. 시간 경과만으로 처리 중 표식을 지우거나 재발급하지 마십시오.

자세한 확인 대기 거래 처리와 적용·복구 원칙은 [KCP 현금영수증 보안 안내](security-kve-2026-2513.md)를 확인하십시오. 복구 시에도 처리 중 표식을 보존하고 취약한 처리 경로를 외부에 다시 열지 않아야 합니다.

## 검증 범위

PHP 7.4·8.4 격리 DB 및 모의 KCP 테스트, 실제 설치 사이트의 PC·모바일 주요 기능과 현금영수증 흐름을 검증했습니다. 초기 수정 단계에서 KCP 공용 테스트 발급·전액 취소를 확인했고, 후속 정합성 수정은 모의 전송으로 검증했습니다. 운영 가맹점, 모든 PG·결제수단·사용자 수정 스킨에 대한 실거래 검증은 아닙니다.

포인트다모아 개발 브랜치의 변경은 포함하지 않습니다.
