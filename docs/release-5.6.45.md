# 그누보드 5.6.45 보안 업데이트 안내

- 배포일: 2026-11-02
- 패치 기준: 5.6.44
- DB 업그레이드: 불필요 (새 DB 변경 없음)
- 삭제 대상 파일: 없음

## 변경 내용

- 비밀글 인증을 게시물별로 분리하여 답글·댓글 인증이 원글이나 다른 게시물의 열람 권한으로 확장되는 문제를 수정했다.
- 답글·댓글·스크랩 저장과 링크·첨부 다운로드에서 현재 게시판 및 게시물의 접근 권한을 확인한다.
- 저장 단계에서도 그룹 가입과 본인·성인확인 조건을 검사한다. 댓글 수정 대상의 유형과 부모 게시물도 확인한다.
- 기존 비밀번호 형식의 인증을 지원하며 작성자·관리자 및 정상 비밀번호 인증 사용자의 이용을 유지한다.

## 업데이트 순서

1. 소스·DB·data 및 개별 수정 파일을 백업하고 글쓰기 등 변경 작업을 잠시 중지한다.
2. 5.6.44 사용자는 패치 ZIP을 적용한다. 이전 버전은 전체 파일과 누적 변경을 검토하여 적용하고 이전 버전에서 필요한 DB 업그레이드를 완료한다. config.php, data 및 별도 수정 파일은 보존·병합한다.
3. 새 공통 라이브러리와 변경한 게시판 처리 파일·구버전 호환 확장을 함께 반영한다. 일부 파일만 적용하지 않는다.
4. 기존 비밀글 비밀번호 인증은 다시 받아야 한다. 로그인 세션 전체를 삭제할 필요는 없다. 사용자 지정 스킨·플러그인이 구 인증 세션을 직접 검사한다면 새 공통 판정에 맞춰 수정한다.
5. 작성자·관리자·비회원의 비밀글 열람, 글·댓글 작성과 수정, 첨부 다운로드를 확인하고 서비스를 재개한다.

비회원 비밀글에 대한 답변은 기존과 같이 관리자만 가능하다. 비밀번호 인증 후 열람과 댓글은 허용된다. 자세한 인증 범위와 적용 유의점은 [게시판 접근통제 안내](board-access-security.md)를 참조한다.

## 검증 범위

PHP 8.4.27 / MariaDB의 격리된 새 설치에서 권한 단위 검증 38개와 실제 HTTP·DB 검증 112개를 통과했다. 회원·비회원의 공개/비밀글 작성·수정·재열람, 댓글 작성·수정, 관리자 역할, 그룹/인증 조건, 첨부 다운로드 및 PC/모바일 응답을 포함한다.

실제 브라우저에서도 권한 없는 직접 요청 차단과 작성자의 비밀 답변 작성, 비회원 비밀번호 인증 후 열람을 확인했다. 사용자 지정 스킨·플러그인 전체를 검증한 것은 아니다. 이번 배포는 PHP 최소 버전 상향이나 별도 결제 기능 전환을 포함하지 않는다.
