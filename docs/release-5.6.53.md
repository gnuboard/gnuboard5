# 그누보드 5.6.53 보안 업데이트 안내

SMS 문자 보내기 화면과 쇼핑몰 분류관리의 보안 문제를 수정했습니다. 새 DB 변경과 삭제 대상 파일은 없으며, 5.6.52 사용자는 패치 파일을 적용할 수 있습니다.

## 개발자 노트

SMS 기능을 사용하는 사이트에서 일반 회원이 이름에 따옴표가 들어간 특수한 값을 넣어 가입할 수 있었습니다. 관리자가 "회원정보 업데이트"로 이 이름을 휴대폰번호 목록에 옮긴 뒤 해당 회원에게 문자를 보내려고 "보내기"나 "추가"를 누르면, 관리자 화면에서 회원이 넣은 스크립트가 실행될 수 있었습니다.

문자 보내기 화면이 이름을 JavaScript 코드 안에 그대로 넣은 것이 원인입니다. 이번 버전부터는 이름·문구·회신번호를 JavaScript 문자열로 안전하게 바꿔 출력하므로, 따옴표가 들어간 값도 글자 그대로만 표시됩니다.

쇼핑몰 분류관리에서는 분류마다 관리 회원을 지정해 다른 관리자에게 일부 분류만 맡길 수 있습니다. 그런데 목록에서만 자기 분류를 보여 주고, 수정 화면과 저장 처리에서는 실제 관리 회원을 확인하지 않았습니다. 그래서 분류관리 권한을 받은 관리자가 다른 관리자의 분류 코드를 직접 넣어 관리 회원을 자신으로 바꾸고, 본인확인·성인인증 설정까지 끌 수 있었습니다.

이제 최고관리자가 아니면 자신이 관리 회원인 분류만 조회·수정·하위 분류 추가할 수 있습니다. 관리 회원 지정은 최고관리자만 할 수 있습니다.

## 패치 노트

- **KVE-2026-3257:** SMS 문자 보내기(adm/sms_admin/sms_write.php)가 JavaScript에 넣는 값을 JavaScript 문자열로 인코딩해 출력합니다.
  - 대상: 개별 보내기 수신자, 문구 불러오기, 재전송 문구·회신번호·수신자 목록
  - 수신자 추가 버튼(adm/sms_admin/ajax.sms_write_person.php)과 그룹 추가 버튼(adm/sms_admin/ajax.sms_write_group.php)의 인자도 같은 방식으로 인코딩합니다.
- **KVE-2026-3258:** 분류관리의 상세 화면(adm/shop_admin/categoryform.php), 저장(adm/shop_admin/categoryformupdate.php), 목록 일괄수정(adm/shop_admin/categorylistupdate.php)에서 관리 회원을 확인합니다.
  - 최고관리자가 아니면 DB에 저장된 관리 회원이 본인인 분류만 처리합니다.
  - 일괄수정에 다른 관리자의 분류가 하나라도 있으면 전체를 거부합니다.
  - 위임 관리자가 보낸 관리 회원 값은 무시합니다.
- **공통 함수:** 분류 관리 회원 확인 함수를 adm/shop_admin/admin.shop.lib.php에 추가했습니다. 이번 변경에 새 PHP 버전 전용 구문이나 함수는 추가하지 않았습니다.

**[릴리즈 노트 및 업데이트 안내]**

- 버전: 5.6.53
- 배포일: 2026-11-17
- 패치 기준: 5.6.52
- DB업그레이드: 불필요 (새 DB 변경 없음)
- 삭제 대상 파일: 없음

1. 파일과 DB를 백업하고 업데이트 중 사이트 이용을 일시 중지합니다.
2. 5.6.52 사용자는 패치 ZIP을 적용합니다. 이전 버전은 전체 배포본을 기준으로 사용자 수정 사항을 병합하고, 기존 data와 DB 설정을 보존합니다. 5.6.51의 삭제 대상 파일 안내도 함께 확인합니다.
3. 분류관리 권한을 다른 관리자에게 맡긴 쇼핑몰은 분류별 관리 회원과 본인확인·성인인증 설정이 의도대로인지 확인합니다. 이번 버전부터 위임 관리자는 분류의 관리 회원을 바꿀 수 없으며, 관리 회원 지정은 최고관리자가 합니다.
4. 이전 버전에서 미완료한 DB 업그레이드가 있다면 관리자 DB 업그레이드에서 완료합니다.
5. PHP 코드 캐시와 별도 CDN·페이지 캐시를 사용한다면 갱신합니다. 다음을 확인한 뒤 서비스를 재개합니다. 문제가 생기면 함께 백업한 이전 코드로 복원합니다.
   - SMS 문자 보내기 화면(수신자 추가, 그룹 추가, 이모티콘 보내기)
   - 쇼핑몰 분류관리(분류 수정, 하위 분류 추가, 목록 일괄수정)

SMS 휴대폰번호 목록과 회원 이름에 따옴표·역슬래시가 들어간 이상한 값이 있는지도 함께 확인하기를 권장합니다. 이번 업데이트로 이런 값은 화면에 글자 그대로만 표시됩니다.

## 검증 범위

PHP 8.3·8.4의 신규 설치본에서 다음을 검사했습니다.

- SMS 문자 보내기의 개별 보내기·수신자 추가·그룹 추가·문구 불러오기·재전송에서 따옴표가 든 값이 글자 그대로 전달되고 실행되지 않음
- 분류관리 위임 관리자의 다른 관리자 분류 조회·수정·일괄수정·하위 분류 추가 거부와 본인 분류의 정상 처리
- 단위 검사, 기존 회귀 검사

웹 설치 화면으로 새로 설치한 사이트에서 다음을 브라우저로 확인했습니다. 수정 전 코드에서는 두 문제가 실제로 재현되었습니다.

- 회원가입 화면으로 넣은 이름의 문자 보내기 화면 동작
- 분류관리의 거부·정상 동작

하위 PHP 버전은 변경 코드에 PHP 5.2보다 새 구문·함수가 없는지 정적으로 검사했습니다.

실제 문자 발송, PHP 8.3 미만 실제 실행, 외부 커스텀 관리자 화면은 이번 검증 범위에 포함하지 않았습니다.
