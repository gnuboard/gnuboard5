# 그누보드 5.6.51 보안 업데이트 안내

쇼핑몰 쿠폰 다운로드, 본인인증 비밀번호 찾기, 현재접속자 화면의 보안 문제를 수정했습니다. 새 DB 변경은 없으며, 5.6.50 사용자는 패치 파일을 적용할 수 있습니다. 이번 버전부터 현재접속자 목록 페이지는 제공하지 않습니다.

## 개발자 노트

로그인한 회원이 다른 사이트의 페이지를 방문하기만 해도, 그 페이지가 몰래 보낸 요청으로 쿠폰존의 포인트 쿠폰이 발급되고 포인트가 차감될 수 있었습니다. 본인인증으로 비밀번호 찾기를 마친 뒤 새 비밀번호를 제출하기 전이라면, 같은 방식으로 다른 사람이 정한 비밀번호로 계정이 바뀔 수도 있었습니다. 두 처리 모두 요청이 사이트의 정상 화면에서 왔는지 확인하지 않는 것이 원인입니다.

이번 버전에서는 쿠폰 발급과 비밀번호 재설정이 정상 화면에서 발급한 토큰을 가진 요청만 처리합니다. 본인인증 후 비밀번호 재설정은 10분 안에 완료해야 하며, 비밀번호를 바꾸면 기존 자동 로그인이 해제됩니다. 최고관리자 계정은 본인인증으로 비밀번호를 재설정할 수 없습니다.

현재접속자 화면은 회원이 보고 있는 페이지 제목을 그대로 보여 주어, 비회원도 비밀글이나 접근 제한 게시판 글의 제목과 그 글을 보는 회원을 알 수 있었습니다. 공개 화면에서는 원래 글의 접근 권한을 다시 확인할 수 없는 구조이므로, 현재접속자 목록 페이지를 제공하지 않고 접속 위치도 기록하지 않도록 했습니다. 상단의 접속자 수 표시는 그대로 유지됩니다.

## 패치 노트

- KVE-2026-3198: 쿠폰존 쿠폰 발급을 POST 요청과 세션 토큰 검증으로 제한했습니다. 쿠폰존 화면과 js/shop.couponzone.js가 토큰을 함께 보냅니다.
- KVE-2026-3199: 본인인증 비밀번호 재설정은 다음 조건을 모두 갖춘 요청만 처리합니다.
  - 재설정 화면에서 발급한 1회용 토큰과 같은 사이트 출처
  - 본인인증 후 10분 이내(G5_CERT_FIND_TTL)
  - 새 비밀번호와 확인 입력이 일치(일치 검사가 동작하지 않던 오류 수정)
- KVE-2026-3199: 비밀번호 변경 후 기존 자동 로그인을 해제하고, 최고관리자 계정은 본인인증 재설정 대상에서 제외했습니다.
- KVE-2026-3200: 현재접속자 목록 페이지(bbs/current_connect.php)는 안내 후 메인으로 이동합니다. 접속 위치·주소를 기록하지 않으며, 헤더의 현재접속자 링크와 현재접속자 스킨을 정리했습니다. 접속자 수 집계는 유지합니다.
- 토큰 비교에는 기존 slow_equals()를 사용하며, 이번 변경에 새 PHP 버전 전용 구문이나 함수를 추가하지 않았습니다.
