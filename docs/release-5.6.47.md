# 그누보드 5.6.47 업데이트 안내

토스페이먼츠의 거래식별자 형식 변경에 대응하고 관리자 부분취소에서 중복 환불을 방지했습니다. 기존 설치는 파일 반영 후 관리자 DB 업그레이드에서 전체 마이그레이션을 실행해 주세요.

## 개발자 노트

토스페이먼츠가 발급하는 XPay TID와 신모듈 paymentKey는 최대 200자까지 원문으로 처리합니다. 기존 거래번호를 재발급하거나 변환할 필요가 없습니다. 주문·개인결제와 가상계좌 통보에서 거래번호의 대소문자를 구분하며, 취소 요청에 포함된 특수문자를 보존합니다.

## 패치 노트

- 관리자 부분취소 한도를 초과 수납액과 실제 결제 잔액 중 작은 금액으로 제한합니다. 오래된 취소 창이나 동시 제출로 환불액이 중복 반영되는 것을 방지합니다.
- 토스 신모듈은 취소 전에 거래번호와 잔액을 대조하고 같은 요청에 같은 멱등키를 사용합니다. PG 승인 후 주문 기록이 실패하면 PG 내역과 쇼핑몰 환불액을 대조한 뒤 처리해 주세요.
- XPay에서는 과세분만 온라인 부분취소할 수 있습니다. 공개 매뉴얼로는 면세분을 총취소금액에 포함하는 규칙을 확정할 수 없어, 면세분을 포함한 요청은 차단합니다. 해당 건은 토스 상점관리자에서 처리하고 쇼핑몰 환불액과 잔액을 대조해 주세요.
