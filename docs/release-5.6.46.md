# 그누보드 5.6.46 업데이트 안내

그누보드만 사용하는 사이트에서 쇼핑몰 잔여 테이블 때문에 DB 업그레이드가 중단되는 문제를 수정했습니다. 이전 업그레이드가 실패했거나 대기 항목이 있는 사이트는 파일 반영 후 관리자 DB 업그레이드에서 전체 마이그레이션을 실행해 주세요.

## 개발자 노트

쇼핑몰 사용 설정이 없거나 꺼져 있으면 쇼핑몰 SQL을 보류하고 공통 DB 변경을 진행합니다. 잔여 쇼핑몰 테이블은 수정하지 않습니다. 이후 쇼핑몰 사용 설정을 켜면 보류한 쇼핑몰 부분만 처리하며 완료된 공통 SQL은 반복하지 않습니다.

쇼핑몰 사용 중 필수 테이블이나 실행에 필요한 기준 컬럼이 없으면 구조 오류를 안내합니다. 선택 테이블의 부재는 기존 조건에 따라 건너뛰며, DB 조회 실패는 구조 오류와 구분합니다. 불완전한 쇼핑몰 전체 구조를 자동 복원하는 기능은 아닙니다.

기존 상태 확인 이력 등록은 SQL 실행이나 실패 복구 기능이 아닙니다. 실패한 업그레이드는 오류 원인을 복구한 뒤 전체 마이그레이션 실행으로 재시도해 주세요.

## 패치 노트

- 쇼핑몰 미사용 사이트의 잔여 테이블로 인한 DB 업그레이드 중단을 방지했습니다.
- 공통 완료·쇼핑몰 보류 및 쇼핑몰 부분 실패 상태를 구분하여 재활성화·재시도를 지원합니다.
- 필수 테이블과 선택 테이블, 구조 조회 실패를 구분하고 관리자 화면에 오류를 표시합니다.
- 과거 성공 이력에서 누락된 쇼핑몰 스키마를 재검사합니다. 간편결제 설정 컬럼의 VARCHAR 길이가 부족하면 확장하며 더 넓은 사용자 정의 컬럼은 보존합니다.
- 기존 마이그레이션 SQL과 체크섬을 유지합니다. PHP 최소 지원 버전 변경과 포인트다모아 기능은 포함하지 않습니다.

**[릴리즈 노트 및 업데이트 안내]**

- 버전: 5.6.46
- 배포일: 2026-11-02
- 패치 기준: 5.6.45
- DB업그레이드: 새 마이그레이션 없음. 기존 실패·보류·누락 항목이 있으면 전체 실행 필요
- 삭제 대상 파일: 없음

1. DB와 파일을 백업하고 업데이트 중 사이트 이용을 일시 중지합니다.
2. 5.6.45 사용자는 패치 ZIP을, 이전 버전은 전체 배포본을 기준으로 사용자 수정 사항을 병합합니다. 기존 data와 DB 설정은 보존합니다.
3. 관리자 DB 업그레이드에서 상태를 확인합니다. 대기·실패·활성 쇼핑몰 보류 항목이 있으면 필요한 DB 권한을 갖춘 상태에서 전체 마이그레이션을 실행합니다. 비밀번호 찾기 저장소가 준비되지 않았다면 20261008_001_abuse_rate, 20261008_002_abuse_rate_transaction을 포함한 선행 변경을 완료해야 합니다.
4. 오류가 발생하면 표시된 테이블·컬럼·권한을 확인하고 복구 후 재실행합니다. 완료된 성공 이력을 일괄 삭제하지 않습니다.
5. 캐시와 주요 화면, 비밀번호 찾기, 사용하는 쇼핑몰 기능을 확인한 뒤 이용을 재개합니다.

과거 성공 이력에서 배송비 데이터 보정만 누락됐는지는 자동 판별하지 않습니다. 정상 무료배송 주문을 잘못 변경하지 않도록 [DB 마이그레이션 안내](database-migrations.md)의 후보 조회·원자료 대조·선택 복구 절차를 따르세요.

## 검증 범위

PHP 8.3·8.4에서 실제 5.6.22 설치 후 전체 파일 덮어쓰기 12개 조합을 검사했습니다. 게시판 전용, 잔여 테이블, 쇼핑몰 설치 후 게시판만 재설치, 정상 쇼핑몰, 불완전 주문 테이블, 선택 로그 테이블 부재를 포함합니다. 재활성화·부분 실패·복구·반복 실행·체크섬, 과거 성공 이력과 컬럼 확장, 배송비 자동 변경 방지 회귀 검사를 통과했습니다. 실제 외부 PG 결제·은행 입금 검증은 포함하지 않습니다.
