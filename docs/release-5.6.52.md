# 그누보드 5.6.52 보안 업데이트 안내

본인인증 갱신, 게시글 스크랩, 쪽지 삭제의 보안 문제를 수정했습니다. 새 DB 변경과 삭제 대상 파일은 없으며, 5.6.51 사용자는 패치 파일을 적용할 수 있습니다.

## 개발자 노트

로그인한 회원이 다른 사이트의 페이지를 방문하기만 해도, 그 페이지가 몰래 보낸 요청으로 회원의 휴대폰번호가 바뀌고 본인·성인인증 정보가 지워질 수 있었습니다. 본인인증 갱신 처리가 요청이 정상 화면에서 왔는지, 실제 본인인증을 거쳤는지 확인하지 않은 것이 원인입니다. 이번 버전부터는 갱신 화면에서 발급한 1회용 토큰과 유효한 본인인증 결과가 있어야만 회원정보가 바뀝니다.

게시글 스크랩은 같은 회원이 동시에 여러 번 요청하면 스크랩·댓글·댓글 포인트가 중복으로 생길 수 있었습니다. 이 경로에는 연속 등록 제한도 적용되지 않았습니다. 이제 같은 글의 스크랩 등록은 한 번만 처리하고, 댓글과 포인트는 그 등록이 성공한 경우에만 처리합니다. 스크랩 댓글에도 연속 등록 제한을 적용합니다.

쪽지는 받는 사람과 보내는 사람의 보관함에 각각 저장됩니다. 그런데 삭제할 때 어느 보관함의 쪽지인지 확인하지 않아, 상대방 보관함의 쪽지까지 지울 수 있었습니다. 이제 자기 보관함의 쪽지만 삭제할 수 있고, 실제로 삭제된 경우에만 새 쪽지 알림을 갱신합니다.

## 패치 노트

- **KVE-2026-3201:** 본인인증 갱신(bbs/member_cert_refresh_update.php)에 갱신 화면의 1회용 토큰, 같은 사이트 출처 확인, 갱신 대상 계정 확인을 적용했습니다.
  - 유효한 본인인증 결과가 없으면 회원정보를 변경하지 않습니다.
  - 사용한 인증 결과는 갱신 후 바로 폐기합니다.
- **KVE-2026-3202:** 스크랩 등록(bbs/scrap_popin_update.php)을 회원·게시물 단위로 한 번만 처리합니다.
  - 댓글·포인트는 스크랩 등록이 성공한 경우에만 처리합니다.
  - 스크랩 댓글에 연속 등록 제한을 적용하고, 스크랩 창에 1회용 토큰과 출처 확인을 추가했습니다.
- **KVE-2026-3203:** 쪽지 삭제(bbs/memo_delete.php)는 요청한 보관함(받은·보낸 쪽지)의 자기 쪽지만 지웁니다.
  - 실제 삭제된 경우에만 새 쪽지 알림과 미열람 수를 갱신합니다.
  - 삭제 토큰은 회원에 묶인 1회용 무작위 값으로 바꿨습니다.
- **공통 함수:** 용도별 1회용 토큰 함수와 MySQL 이름 잠금 함수를 lib/common.lib.php에 추가했습니다. 이번 변경에 새 PHP 버전 전용 구문이나 함수는 추가하지 않았습니다.

**[릴리즈 노트 및 업데이트 안내]**

- 버전: 5.6.52
- 배포일: 2026-11-16
- 패치 기준: 5.6.51
- DB업그레이드: 불필요 (새 DB 변경 없음)
- 삭제 대상 파일: 없음

1. 파일과 DB를 백업하고 업데이트 중 사이트 이용을 일시 중지합니다.
2. 5.6.51 사용자는 패치 ZIP을 적용합니다. 이전 버전은 전체 배포본을 기준으로 사용자 수정 사항을 병합하고, 기존 data와 DB 설정을 보존합니다. 5.6.51의 삭제 대상 파일 안내도 함께 확인합니다.
3. 본인인증 갱신 스킨(member_cert_refresh.skin.php)과 스크랩 창 스킨(scrap_popin.skin.php)을 직접 만든 테마는 폼에 token 숨은 필드를 추가해야 합니다. 기본 스킨을 참고하며, 추가하지 않으면 본인인증 갱신과 스크랩 등록이 거부됩니다. 쪽지 스킨은 변경이 필요 없습니다.
4. 이전 버전에서 미완료한 DB 업그레이드가 있다면 관리자 DB 업그레이드에서 완료합니다.
5. PHP 코드 캐시와 별도 CDN·페이지 캐시를 사용한다면 갱신합니다. 다음을 PC·모바일에서 확인한 뒤 서비스를 재개합니다. 문제가 생기면 함께 백업한 이전 코드로 복원합니다.
   - 본인인증 갱신 화면
   - 게시글 스크랩(댓글 포함)
   - 받은·보낸 쪽지 삭제

이미 중복으로 생긴 스크랩·댓글·포인트는 이번 업데이트로 회수되지 않습니다.

## 검증 범위

PHP 8.3·8.4의 신규 설치본에서 다음을 검사했습니다.

- 본인인증 갱신 요청 위조·토큰 재사용·인증 결과 없음 거부와 정상 갱신
- 스크랩 동시 12요청에서 1건만 처리와 연속 등록 제한
- 쪽지의 상대 보관함 삭제 거부와 자기 쪽지 삭제
- 단위 검사, 기존 회귀 검사

웹 설치 화면으로 새로 설치한 사이트에서 브라우저로 세 기능의 정상·거부 동작을 확인했습니다. 수정 전 코드에서는 세 문제가 실제로 재현되었습니다. 하위 PHP 버전은 변경 코드에 PHP 5.2보다 새 구문·함수가 없는지 정적으로 검사했습니다.

실제 본인인증 사업자를 거친 확인, PHP 8.3 미만 실제 실행, 실제 휴대전화 기기, 외부 커스텀 스킨은 이번 검증 범위에 포함하지 않았습니다.
