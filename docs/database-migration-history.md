2012~2013년에 `config_form.php`, `board_form.php`, `member_form.php`, `qa_config.php` 등에서 수행하던 보정은 그누보드5 최초 배포 스키마를 형성하는 과정이었다. 이 항목들은 위 연속 패치보다 앞선 기준선이며 현재 `install/gnuboard5.sql`과 `install/gnuboard5shop.sql`에 포함된다. 제거 후 설치 스키마에서 누락된 필드는 별도로 대조해 보완했다.

팝빌 알림톡 테이블·설정과 게시판 알림 필드는 `7e8eff539`에서 기능과 함께 제거됐으므로 현재 목표 스키마에 다시 만들지 않는다. 반면 같은 도입 커밋의 마케팅 동의 필드는 유지돼 별도 마이그레이션으로 남겼다. 데이터 삭제가 필요한 쿠폰 중복 정리는 자동 수행하지 않으며, 중복이 있으면 고유 인덱스 생성 실패를 그대로 보고해 운영자가 데이터를 검토하도록 한다.

초기 이전 작업에서 확인된 복합 `ALTER TABLE`의 부분 적용 가능성과 누락된 데이터 보정은 `20260904_002_reconcile_partial_schema`, `20260904_003_backfill_legacy_data`에서 보완한다. 두 마이그레이션은 누락 컬럼과 인덱스를 개별 검사하고, 장바구니 배송비·회원 이미지 기본값·콘텐츠 SEO 데이터를 보정하며 SEO 컬럼 길이를 신규 설치 정의와 일치시킨다.
