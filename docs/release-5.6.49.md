# 그누보드 5.6.49 업데이트 안내

영카트 관리자 엑셀배송처리에서 정상 XLS 파일을 등록해도 “올바른 방법으로 이용해 주십시오.”라는 알림으로 중단되는 문제를 수정했습니다.

## 개발자 노트

엑셀배송처리의 보안 검증에 필요한 토큰이 업로드 화면에서 전달되지 않아 파일을 읽기 전에 요청이 차단되었습니다. 이번 수정은 등록 화면에서 토큰을 함께 전송하여 정상적인 배송정보 등록이 가능하도록 합니다. 기존 보안 토큰 검증은 유지합니다.

## 패치 노트

- `adm/shop_admin/orderdelivery.php`의 업로드 폼에 `get_admin_token()`으로 생성한 hidden 토큰을 추가했습니다.
- 정상 토큰 통과와 빈 토큰·변조·재사용·이전 창 토큰 거부를 확인하는 회귀 검사를 추가했습니다.

**[릴리즈 노트 및 업데이트 안내]**

- 버전: 5.6.49
- 배포일: 2026-11-11
- 패치 기준: 5.6.48
- DB업그레이드: 불필요 (새 DB 변경 없음)
- 삭제 대상 파일: 없음

1. 파일과 DB를 백업하고 업데이트 중 사이트 이용을 일시 중지합니다.
2. 5.6.48 사용자는 패치 ZIP을 적용합니다. 이전 버전은 전체 배포본을 기준으로 사용자 수정 사항을 병합하고 기존 data와 DB 설정을 보존합니다.
3. 이번 문제의 제품 수정 파일은 `adm/shop_admin/orderdelivery.php`입니다. `orderdeliveryupdate.php`의 보안 토큰 검증은 제거하지 마세요.
4. 이전 버전에서 미완료한 DB 업그레이드가 있다면 관리자 DB 업그레이드에서 완료합니다.
5. PHP 코드 캐시를 사용하면 새 파일 반영을 확인하고, 열려 있는 엑셀배송처리 창을 닫았다가 다시 엽니다. Excel 97–2003 통합문서(.xls) 업로드와 배송정보 반영을 확인한 뒤 서비스를 재개합니다.

## 검증 범위

PHP 8.3·8.4에서 토큰 검증 6건과 PHP 문법 검사를 수행했습니다. 기존 개발 환경의 로컬 HTTP 경로에서 실제 multipart XLS 업로드로 성공 1건·실패 0건을 확인하고, DB의 송장번호·택배사 저장 및 임시 주문·장바구니의 준비→배송 전환을 확인했습니다. 임시 데이터는 검사 후 제거했습니다. 빈 토큰·변조·재사용 요청도 거부되었습니다.

PHP 7.4 실행 환경과 브라우저 UI, 배송안내 메일·SMS 및 외부 에스크로 연동은 이번 검증에 포함하지 않았습니다.
