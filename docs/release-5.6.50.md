# 그누보드 5.6.50 보안 업데이트 안내

접근이 제한된 게시판과 인증이 필요한 상품의 보조 조회 경로에서 권한 검사를 강화했습니다. 새 DB 변경은 없으며, 5.6.49 사용자는 패치 파일을 적용할 수 있습니다.

## 개발자 노트

회원 그룹이나 본인·성인 인증으로 콘텐츠를 제한하는 사이트에서는 직접 상세 화면뿐 아니라 최신글, RSS, 검색, 이벤트와 보조 목록에도 같은 접근 정책이 적용되어야 합니다. 이번 업데이트는 이러한 조회 경로에서 현재 사용자의 권한을 확인하여 제한된 정보가 노출되지 않도록 보강합니다.

권한이 바뀌면 다음 조회부터 변경 사항을 반영하며, 공개 최신글의 수정·삭제 시 기존 캐시 삭제 동작도 유지합니다. 인증 조건이 없는 공개 게시판과 상품은 기존과 같이 이용할 수 있습니다.

## 패치 노트

- **KVE-2026-3196:** 게시판 목록·최신글·통합 검색·새글의 그룹, 조회 레벨 및 인증 정책을 검사합니다. RSS는 비회원에게 공개된 게시판만 제공합니다.
- **KVE-2026-3197:** 주분류와 추가 분류의 본인·성인 인증 조건을 상품 검색, 이벤트, 관련상품, 후기·문의, 위시리스트와 오늘 본 상품 등 보조 목록에 적용합니다.
- 두 번째 상품 분류가 비어 있어도 세 번째 분류의 인증 조건을 검사합니다.
- 최신글 캐시를 현재 게시판 접근 권한 확인 후 사용하고, 글 수정·비밀글 전환·삭제 시 무효화합니다.
- 외부 상품 목록 쿼리는 한 번만 실행하여 원래 순서와 중복 행을 유지하면서 접근 불가 상품을 제외합니다.
- 신규 라이브러리 lib/shop.visibility.lib.php와 lib/sql_rows.lib.php를 추가합니다.

**[릴리즈 노트 및 업데이트 안내]**

- 버전: 5.6.50
- 배포일: 2026-11-12
- 패치 기준: 5.6.49
- DB업그레이드: 불필요 (새 DB 변경 없음)
- 삭제 대상 파일: 없음

1. 파일과 DB를 백업하고 업데이트 중 사이트 이용을 일시 중지합니다.
2. 5.6.49 사용자는 패치 ZIP을 적용합니다. 이전 버전은 전체 배포본을 기준으로 사용자 수정 사항을 병합하고 기존 data와 DB 설정을 보존합니다. 두 신규 라이브러리를 포함하여 변경 파일을 함께 적용합니다.
3. 커스텀 상품 SQL과 테마·스킨에도 접근 필터를 적용합니다. 외부 item_list 결과는 공통 sql_fetch_array·sql_num_rows·sql_data_seek·sql_free_result API로 처리해야 하며 직접 mysqli_*를 호출하는 스킨은 전환이 필요합니다. 외부 쿼리의 LIMIT 전에 공통 필터를 적용하면 목록이 덜 채워지는 현상을 피할 수 있습니다.
4. 이전 버전에서 미완료한 DB 업그레이드가 있다면 관리자 DB 업그레이드에서 완료합니다. PHP 코드 캐시와 별도 CDN·페이지 캐시를 사용하는 경우 변경 사항이 반영되도록 무효화합니다.
5. 비회원·일반 회원·인증 회원의 게시판과 상품 노출, 최신글 수정·삭제 반영, PC·모바일 화면을 확인한 뒤 서비스를 재개합니다. 문제가 생기면 함께 백업한 이전 코드로 복원합니다.

기존 정적 이미지 URL과 외부 검색 색인은 이번 PHP 조회 정책 패치만으로 제거되지 않습니다. 상품에 지정한 분류의 제한을 검사하며 상위 분류 제한을 자동 상속하는 새 정책은 도입하지 않았습니다.

## 검증 범위

PHP 8.3·8.4에서 각각 HTTP·DB·캐시 통합 134개, 게시판 회귀 38개, 접근 정책 28개, 장바구니 46개 및 분류 메뉴 8개 경로를 검증했습니다. 최종 수정 후 Chrome HTTPS에서 최신글 캐시 갱신, 접근 제한, 인증별 상품 검색·이벤트, 가격 정렬, 모바일 스킨 및 인증 취소 반영을 확인했습니다.

모바일 검증은 Chrome의 모바일 스킨 선택으로 수행했으며 실제 휴대전화 기기 검증은 아닙니다. PHP 7.4 실행, 외부 커스텀 스킨 및 실제 PG 결제 통신은 이번 검증 범위에 포함하지 않았습니다.
